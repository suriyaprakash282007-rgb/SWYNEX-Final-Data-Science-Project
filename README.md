# Final Data Science Project

## Project
End-to-end regression case study using the public scikit-learn Diabetes dataset.

## Files
- `Final_Data_Science_Project.ipynb` – complete notebook with data preparation, EDA, modeling and conclusions.
- `diabetes_dataset.csv` – dataset used by the notebook.
- `requirements.txt` – Python packages required.

## How to run

### 1. Install Python
Python 3.9+ is recommended.

### 2. Install dependencies
Open Command Prompt/Terminal in this folder and run:

```bash
pip install -r requirements.txt
```

If `pip` is not recognized, use:

```bash
python -m pip install -r requirements.txt
```

### 3. Start Jupyter
```bash
jupyter notebook
```

Open `Final_Data_Science_Project.ipynb` and run the cells from top to bottom.

## Workflow
1. Problem statement
2. Dataset loading
3. Data cleaning and validation
4. Exploratory data analysis
5. Train/test split
6. Linear Regression baseline
7. Random Forest model
8. MAE, RMSE and R² evaluation
9. Actual-vs-predicted visualization
10. Conclusions, limitations and future scope

## Dataset
The CSV is generated from the Diabetes regression dataset distributed through scikit-learn. It contains 442 observations, 10 input features and one target variable.
